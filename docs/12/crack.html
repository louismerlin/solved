GLASSHEADS, pt. 5 Crack the ******

This challenge can be found on the inside of the cover of issue 12.

The challenge mentions "chip codes". This is a very valuable hint: they are used in CDMA (Code Division Multiple Access), where several transmitters share the same channel at the same time.

Each bit is sent as +1 (for a 1) or -1 (for a 0), and multiplied by the transmitter's chip code. Child A has the code +1 +1, so it sends +1 +1 for a 1 and -1 -1 for a 0. Child B has the code +1 -1, so it sends +1 -1 for a 1 and -1 +1 for a 0. Both children transmit at once, and the two signals are added together on the wire. The sum is what the black chart shows.

Click the bits below to see how two bytes combine into a signal like the one inside the cover:

There are only four possible pairs on the wire:

pair      A  B
-2  0  => 0  0
 2  0  => 1  1
 0 -2  => 0  1
 0  2  => 1  0

The cover shows 48 chips, so 24 bits per child: three 8-bit ASCII characters each. Each row of the chart carries exactly one character from each child. Reading the characters alternately (A, B, A, B, A, B), we get our six-letter word.
