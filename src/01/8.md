# OGN Challenge #8

This challenge was originaly only available in the Kickstarter edition of the OGN.

There are an extra few pages at the end of the book, with the challenge inside.

This bonus chapter was later released at the end of issue 12.

## The Setup

> Help Ruth gain access to the guards' door system! Looks like we're going to need some sort of code...

We are also given a link to a web portal, as well as a copy of the QR code printed in the comic book.

## The Key

The web portal asks us for a "TOTP" code. This is a [time-based one-time password](https://en.wikipedia.org/wiki/Time-based_one-time_password), a popular method of 2-factor authentication.

The QR code printed on the back of the goon in the comic (also given on the challenge page) should allow you to add a TOTP "account" to your 2fa application of choice (also, some operating systems have a default built-in app for this, such as "Passwords" for iOS).

Using the code generated by the app, you can unlock the door and get the flag.
